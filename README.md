# LUNO — نموذج متجر ساعات وإكسسوارات

نموذج واجهة عربي (RTL) لمتجر إلكتروني خيالي باسم **LUNO**، مبني بـ **React 19 + Vite** باستخدام JavaScript عادي وCSS مستقل. الهدف من المشروع هو استكشاف الشكل والتجربة البصرية فقط: لا يوجد Backend، ولا قاعدة بيانات، ولا تسجيل دخول، ولا دفع حقيقي.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يطبعه Vite (عادةً `http://localhost:5173`).

لإنشاء نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## ما الذي يضمه النموذج؟

- شريط عروض وتوصيل أعلى الصفحة.
- هيدر ثابت يضم الشعار، روابط التنقّل، البحث، المفضية، وسلة التسوّق، وحسابات العرض.
- قسم Hero بصورة رئيسية وعنوان وزرَّي دعوة لاتخاذ إجراء، مع شريط عرض تجريبي قابل للتفعيل.
- شريط أرقام تجريبية (بيانات وعرضة فقط، قابلة للتعديل).
- قسمان مختصران للفئات: الساعات والإكسسوارات، كل قائمتان بصور وتعداد قطع.
- شبكة من ٨ منتجات تجريبية (٤ ساعات + ٤ إكسسوارات) مع الاسم والسعر والخصم وزر الإضافة والقلب.
- بطاقات منتجات مع تقييم تجريبي، وعدد مراجعات، ونسبة خصم محسوبة، وبطاقة رقم للموضة.
- قسم الأكثر مبيعًا وقسم وصول حديثًا وأقسام قائمة مختصرة موحّدة (ProductShowcase).
- قسم عروض بصري ببانر كبير ومؤقت تنازلي تجريبي قابل للتشغيل/الإيقاف/إعادة الضبط، وقائمة قطع العروض.
- قسم الآراء مع بطاقات تعليقات تجريبية موضّحة بأنها محتوى للعرض فقط.
- كتالوج كامل مع بحث فوري وتصفية حسب الفئة والسعر، وفرز (الأحدث، السعر الأقل، الأعلى، التقييم)، وحالة "لا توجد نتائج".
- سلة جانبية تفتح من اليسار: تعديل الكميات، حذف القطع، شريط تقدّم للتوصيل المجاني، وملخص الأسعار.
- درج جانبي للمفضية من اليسار، مع الإضافة للسلة والإضافة الجماعية وإزالة القطع.
- لوحة حساب كاملة (تسجيل دخول / إنشاء حساب / استعادة كلمة المرور) بخطط صورة وثيم، مع تحقق من الحقول ورسائل أخطاء وإظهار كلمة المرور.
- قائمة تنقل جانبية للموبايل تفتح من اليمين، مع بحث سريع داخل القائمة.
- تذييل يضم معلومات التوصيل والاستبدال والتواصل وروابط المصادر.
- ظهور تدريجي للعناصر عند التمرير، وتأثيرات hover ناعمة، واحترام `prefers-reduced-motion`.
- تنبيهات (Toast) عند الإضافة أو الحذف أو المفضية، مع إشارات بصرية على أيقونات السلة والمفضية.
- مكوّنات ذكية: `SmartImage` (هيكل تحميل + بديل)، `Stars` (تقييم)، `useCountdown` (عدّاد)، `useFocusTrap` (تركيز داخل الأدراج).
- نافذة تفاصيل منتج كاملة: معرض صور متعدد مع مؤشرات اختيار، وصف، سعر وخصم، خيارات اللون/الخامة، وإضافة إلى السلة والمفضية.
- أدوات استكشاف: مقارنة الساعات المختارة، واقتراحات إكسسوارات مقترحة لكل منتج.
- قسم أسئلة شائعة وأقسام معلومات الشحن والاستبدال، ببيانات تجريبية قابلة للتعديل.
- لوحة تحكم إدارية (تجريبية) تفتح من زر القفل في الهيدر (رمز الدخول: `2134`)، تضم نظرة عامة، الطلبات، المنتجات، المخزون، العملاء، العروض والخصومات، التقارير (مع تصدير CSV محلي)، والإعدادات. شاشة قفل مع إظهار/إخفاء الرمز وانتقال حركي، وزر «قفل اللوحة» للعودة. التغييرات محلية في الواجهة (حالة الفتح محفوظة في `sessionStorage`).

## التفاصيل التجريبية الحالية

- كل الأقسام والتعريفات قابلة للتعديل من ملفات البيانات فقط.
- نافذة التفاصيل تعمل كواجهة تفاعلية بحتة، وتحافظ على نفس الهوية البصرية.
- أدوات الاستكشاف (المقارنة والاقتراحات) تفاعلية واجهة فقط، وبياناتها من ملف المنتجات.

## التعديل والتخصيص

### المنتجات

كل شيء في `src/data/products.js`. لتغيير منتج:

```js
{
  id: 'aura-classic',            // معرّف فريد
  name: 'ساعة أورا الكلاسيكية',
  tagline: 'جلد طبيعي بلون الكراميل',
  category: 'watches',           // watches أو accessories
  categoryLabel: 'ساعات',
  price: 420,
  oldPrice: 525,                 // أو null
  badge: 'الأكثر مبيعًا',         // أو null
  bestSeller: true,              // لبناء قسم الأكثر مبيعًا
  isNew: false,                   // لبناء قسم وصول حديثًا
  rating: 4.9,                    // تقييم تجريبي
  reviews: 128,                   // عدد مراجعات تجريبية
  createdAt: '2026-08-12',       // للترتيب حسب الأحدث
  image: '/images/watch-aura.jpg',
  alt: 'وصف الصورة لقارئ الشاشة',
  imageCredit: { ... },
}
```

- الصور توضع في `public/images` وتُستدعى بمسار يبدأ بـ `/images/...`.
- لإضافة منتج جديد، أضيفي كائنًا جديدًا إلى مصفوفة `products` فقط.
- عدّاد السلة والسلة والملخص تتحدّث تلقائيًا.

### البيانات التجريبية (عروض، أرقام، آراء)

في `src/data/content.js`:

- `stats` و`statsNote`: أرقام تجريبية للعرض فقط.
- `offer` و`offer.note`: إعدادات العرض وتفاصيل العدّاد.
- `reviews` و`reviewsNote`: آراء تعليقية محتملة لاستبدالها بالحقيقية.

### الفئات وروابط التنقّل والتواصل

في `src/data/content.js`:

- `categories`: نص وصورة كل فئة.
- `navLinks`: روابط الهيدر والقائمة الجانبية.
- `contact`: البريد، الهاتف، وحساب إنستغرام.
- `shippingThreshold`: حد التوصيل المجاني (افتراضيًا ٢٠٠ ر.س).

### الألوان والخطوط

المتغيرات في أعلى `src/styles/global.css`:

```css
--cream: #f5f1e8;      /* أوف وايت */
--olive: #5f6b4f;      /* أخضر زيتوني */
--olive-deep: #3e4635;
--beige: #d9c9b2;      /* بيج */
--clay: #a96443;       /* لون دافئ للمخصومات والتقييمات */
```

الخطوط محمّلة من Google Fonts في `index.html`:

- **Alexandria** للعناوين.
- **Tajawal** للنصوص.
- **Cormorant Garamond** للشعار والعناصر اللاتينية.

## ملاحظات مهمة

- الدفع غير مفعّل. زر "إتمام الطلب" يعرض تنبيهًا توضيحيًا فقط.
- حالة السلة والمفضية والبحث محفوظة في الذاكرة أثناء الجلسة، وتُفقد عند إعادة تحميل الصفحة.
- الصور من Pexels ومستخدمة وفق ترخيص Pexels. التفاصيل الكاملة في [CREDITS.md](./CREDITS.md) أو صفحة `/credits.html`.
- واجهة الحساب تجريبية بالكامل: لا توجد مصادقة حقيقية ولا تُحفظ أي بيانات أو كلمات مرور.
- العرض والعدّاد والتقييمات والآراء محتوى تعليمي/تجريبي للعرض فقط.
- لوحة التحكم تجريبية: رمز الدخول `2134` (للعرض فقط، يُحفظ في `sessionStorage`). لا توجد مصادقة حقيقية ولا حفظ بيانات حساسة.
- المشروع غير مخصص للإنتاج كما هو: لا يوجد Checkout، ولا إدارة مخزون، ولا تحليلات، ولا SEO متقدم.
